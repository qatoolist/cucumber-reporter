# v0.3.0 review status

Updated 2026-11-08. **Release commit for v0.3.0.** Round 20 passed dev review with no Blocker, High or Medium findings; the identity limit is accepted. After round 20: in-repo browser UI checks with ten mutants (`make ui-check`, run in CI), start and finish times on retry attempts, and plainer wording for the consistency refusals. The clean-commit release gate and Chromium/Firefox/WebKit CI passed on the commit before the release commit, which changes only the version and release wording; the tag follows the same checks on the release commit; the release owner ran the Comet checks and the scripted Comet checklist (6/6).
This record distinguishes implemented changes, verification, documented format
limitations and external release requirements. Older sections below are historical
receipts, not claims about the current tree.

The user explicitly removed cross-input rerun merging from v0.3.0. Repeated
locations across inputs are refused; disjoint shards and retries within one input
remain supported. Shard labels and ordered reruns are the approved new-feature
work for [v0.3.1](../0.3.1-roadmap.md). No other correctness defect is deferred by
that decision. `-reruns`, config `reruns` and public Reruns fields do not ship.

## UI follow-up — evidence action scope

The user found that the failure summary hid **View evidence** when the failed step
had no attachment, even though hooks or prior attempts had attachments. The action
now counts scenario attachments across the current execution and earlier attempts
(without duplicating the final execution). It prefers the failed step's evidence,
then other current-step/hook evidence, then the most recent earlier evidence.
Earlier-attempt links select that attempt and open its details before focusing the
attachment; repeated clicks also restore the intended attempt after a manual switch.

Validation: 15 Node tests passed, report-package tests and generated-asset/golden
checks passed, and browser-tagged tests compiled. Native Comet verified the user's
real Ruby case (View evidence 15), repeated clicks after collapse, and a derived
retry-only evidence case. The corrected real sample is
`dist/preview-evidence-fix/html-597012720/index.html`. Earlier generated reports are
static snapshots and retain their older UI. No Chrome was launched for this follow-up.
