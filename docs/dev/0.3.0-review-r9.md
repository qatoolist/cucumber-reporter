## Validation and limits

Final offline validation passed:

- `make verify`: formatting; vet and lint with and without browser build tags;
  race tests in all seven packages. Lint v2.15.0 was built with Go 1.27.3.
- All six fuzz targets, 10 seconds each: Parse, Messages, Render, RedactionJSON,
  JS minifier and CSS minifier.
- Six browser-free Node tests, including declared labels versus execution anchors.
- Golden output, CSP and generated minified-asset parity. Embedded plain-report data
  is unchanged in all four golden fixtures. HTML bytes change with the banner-link
  script and its CSP hash; this is not a claim of unchanged HTML bytes.
- The CI enhanced showcase generation command publishes its HTML and ZIP locally.
- `git diff --check` is clean.

Browser, print and cross-browser suites were not launched locally, and no CI run
was dispatched. No commit, push, tag or publication was made.

The remaining intentional limits are documented: legacy subset collision context;
identical-name row line moves; inline legacy Background numbering; HAR name/value
header pairs; and per-scenario duration floors without a suite-total duration gate.
A trailing standalone Background is still refused. Run-hook identity uses stable
logical input names and within-stream ordering, and synthetic hooks can display line 0.
